## Current architecture

```
kaggriculture_project/
  main.py         <- THE SUBMISSION (single file, zero deps, AST-generated by build.py)
  build.py        <- AST-bundler: agent/*.py -> flat main.py (never edit main.py by hand)
  agent/          <- modular source (edit here, then rebuild)
    rules.py        verified mechanics constants + pure formulas (no deps)
    state.py        read-only wrapper over obs
    market_model.py price-aware sell pacing / glut throttling
    roi.py          crop & animal $ economics (CropEconomics/AnimalEconomics)
    tasks.py        per-turn opportunity scanner, emits scored tasks (tier + $ - alpha*dist)
    scheduler.py    greedy tier-then-value/distance task->unit assignment (no search)
    planners.py     crop-mix (water-filling w/ batch price), animals, expansion, hiring
    opponent_model.py  public-tile-only opponent supply inference
    strategy.py     orchestrates everything into one action/turn
    agent.py        entrypoint: SIGALRM 0.8s deadline + try/except safe fallback
  tests/verify_rules_against_real_env.py  empirical rules check vs real env (ALL PASS)
  tools/run_match.py, tools/ablation.py   benchmark + subsystem ablation harness
  docs/  RESEARCH_SUMMARY | ARCHITECTURE | STRATEGY | TESTING_AND_RESULTS | VERIFIED_VS_INFERRED | ROADMAP
  official_env*, official_env_beginner/   reference copies of installed kaggle_environments 1.32.2 source
```

Design pillars: no custom simulator (the real `kaggriculture` env is used for
every test); stateless per-turn recomputation (only exception: sticky
`planners._committed_tiles` tile cache, self-resets at step 0); greedy
matching instead of search (movement is obstacle-free Manhattan, reward
structure is closed-form — see `docs/ARCHITECTURE.md`).

   (`ANIMAL_PROFIT_MARGIN`). Ablation showed animals ≈ −$1,239 before the margin fix;
