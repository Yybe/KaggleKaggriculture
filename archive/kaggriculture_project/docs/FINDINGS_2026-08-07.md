## 11. Fast parallel harness (tools/tournament_fast.py)

After candidate9's 20-seed gate took ~17 min serial, built a parallel
harness to shrink iteration wall time: `tools/tournament_fast.py` runs
games in a `ProcessPoolExecutor`, loads each agent ONCE per worker via an
initializer (no per-game runpy of the 78KB built file), reports the same
mean_margin + min_margin summary as `tournament.py`, and adds timing
benchmarks + a `--check N` determinism guard (plays N seeds twice and
asserts rewards are bit-identical across process counts).

Measured on the promoted candidate9b/baseline builds, 20 seeds x 4
matchups x 2 candidates = 160 games: **151s wall vs ~1,136s estimated
serial = 7.5x speedup** on 16 cores (median 6.3s/game). Same-seed games
are bit-identical across `--workers 1/4/8`, confirming determinism. This
cuts a full gate from ~20 min to ~3 min and makes cheap the dozens-of-
seeds iteration the marginal candidate9b pass needs before any next
promotion.
## 12. candidate9e: herd-throughput fix ROOT-CAUSED + promoted

**Root cause (live trace, seed 202 vs starter, tools/trace_animal_planner.py).**
The section-10 hypothesis ("scheduling/feeding throughput on a 15+ animal
herd") was REVISED. The stall is not the grown herd's feed cost -- the
herd *never grows past 2* in the first place. Trace evidence:

- Day 0 buys 3 COW + 2 SHEEP; an empty PASTURE exists at (1,0) from day 6.
- `plan_animal_investment` proposes `COW@(1,0) build=False` (reuse the
  empty pasture) EVERY SINGLE DAY through day 28. The asset is wanted.
- Yet `carried` = {COW:0,SHEEP:0} from day 6 to the end, and the day-12
  task dump has ZERO PLACE tasks: 2 COW + 2 SHEEP sit in the shed
  (~$1,800 locked capital) all 720 steps. `C:0/0 P:1/2` = 1 empty pasture
  NEVER filled.

**Two concrete bugs (both in tasks.py):**

1. **PICKUP/PLACE never survive the greedy scheduler.** Animal PICKUP and
   PLACE are tier-3 with value 20/25, but `ALPHA=3/tile` distance penalty
   makes a unit 8-13 tiles from the shed score `20-30=-10` vs a nearby
   PLANT's `6-3=+3`. Every turn the scheduler reassigns (no commitment),
   so the ~2-turn pickup->place round trip is perpetually preempted by
   planting. Fix: value the PICKUP and PLACE at the animal's own cost
   (COW 400 / SHEEP 500) so a shed->pasture trip beats routine planting.

2. **`_structure_wants_animal` returned dict-first**: PASTURE -> "COW"
   unconditionally, so SHEEP could never be picked up or placed (structurally
   impossible). Fix: prefer an animal of a compatible kind we actually own
   (shed or carried), falling back to first compatible kind.

**Outcome (seed 202 trace):** placed COW now ramps 0->1 (d2), 2 (d4), 3
(d6), 4 (d8), 6 (d12), 7 (d16) -- vs the old auto-2. Final vs
starter 57,323 -> 68,161 (+$10.8k).
